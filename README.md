# To-Do List (Python + SQLite)

A simple command-line to-do list app built with Python and SQLite.

## Features
- Add, show, edit, and delete tasks
- Mark tasks as done
- Show only pending tasks
- Each task stores its creation date
- Data is saved permanently in a SQLite database

## How to run
1. Install Python 3
2. Run: `python main.py`

## What I learned
- Basic SQL: INSERT, SELECT, UPDATE, DELETE, WHERE
- Using sqlite3 in Python
- Why `commit()` is needed to save changes
